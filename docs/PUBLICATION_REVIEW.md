# 公开发布检查清单

## 仓库包含

- 知识图谱抽取、合并、Neo4j 导入与检索代码
- 基于图谱证据的问答流程
- 环境变量配置模板、依赖说明、测试和架构文档

## 仓库不包含

- 任何特定领域名称、应用描述、专用提示词或领域本体
- PDF、Markdown、HTML、JSON、CSV 等用户数据和处理结果
- 演示材料及 Office/PDF 元数据
- 压缩包、缓存、日志、数据库文件和大体积产物
- `.env` 及任何 API Key、Token、账号、密码
- 本机绝对路径和个人目录信息
- 姓名、证件或教育信息、电话、邮箱等身份标识

## 检查范围

- 常见密钥、Token、密码赋值与邮箱模式
- Windows 用户目录和常见绝对路径模式
- 特定领域关键词与数据文件
- Git 历史与大文件
- Python 语法、单元测试和命令行入口

## 发布前仍需确认

1. 确认代码的公开权利及依赖许可证是否符合预期。
2. 选择并添加合适的开源许可证；当前版本没有替所有者做授权决定。
3. 用个人测试配置完成一次真实模型服务和 Neo4j 的端到端验证。
4. 提交前再次检查暂存文件，避免将 `.env`、数据或运行产物手动加入。

本清单只覆盖当前仓库文件；使用者自行加入的数据和配置需要另行检查。
